# Target Cyber Arena — Bug Hunt Challenge 🏆

Welcome to the **Target Cyber Arena**! This is an interactive gaming and artifact store web application for Target International School students.

## 🎯 Your Mission: Bug Bounty Detective
There are intentional UI layout flaws and JavaScript bugs planted across this codebase.

Your objective:
1. Open this repository in **VS Code**.
2. Launch it using **Live Server**.
3. Inspect the UI layout and check the browser console (`F12`).
4. Direct your **AI Agent** (Cline, Roo Code, Copilot, Cursor) to find, explain, and fix the bugs!
5. Log each bug and your agent prompt in your student worksheet to claim your score.

## 🚀 Getting Started
```bash
git clone https://github.com/IsmailTheNormal/target-cyber-arena.git
```
Open `index.html` with Live Server in VS Code. Happy hunting!
